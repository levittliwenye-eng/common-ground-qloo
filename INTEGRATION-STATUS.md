## Real Qloo integration verified on 2026-10-09

The personal event key arrived on 2026-10-09 and is stored as a secret in Sites. Environment revision 1 was applied to a successful private deployment. A direct check using this application's HTTP client completed two searches and all four Insights requests with HTTP 200; the Search wrapper was `results` and the Insights wrapper was `results.entities`. The shared candidate pool contained 20 movies and returned three choices. No API response data or credential was saved in the source repository.

The first deployed live calls exposed a workerd compatibility failure: `redirect: 'error'` is rejected before a request is sent. The client now uses manual redirects and rejects 3xx responses, preserving the fixed-origin credential boundary. Eight tests, type checking and the production build passed. The fixed version was privately deployed successfully. Authenticated MCP calls resolved the two test movies (with explicit years for the ambiguous title) and completed the live recommendation workflow.

A separate real Insights check confirmed numeric affinities in descending order for both queries, movie-only responses, and exact membership of the same fixed pool for both people. Missing-evidence exclusion remains covered by synthetic tests; this live check had no missing candidate results. Private response data, entity IDs and the key are excluded from the source repository. A public browser walkthrough has not been released; anonymous visitors still reach the expected sign-in page.
